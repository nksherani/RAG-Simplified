Retrieval-Augmented Generation (RAG) Flow

Visual guide to the Ingestion and Runtime Query pipelines

flowchart TD
    %% INGESTION PHASE
    subgraph Phase1["Phase 1: Ingestion & Indexing (Offline)"]
        direction TB
        docs["📄 Raw Knowledge Base (PDFs / Docs)"] --> chunk["✂️ Text Chunking"]
        chunk --> emb1["🧠 OpenAI Embedding Model"]
        emb1 --> vdb[("🗄️ Vector Database / Store")]
    end

    %% RUNTIME PHASE
    subgraph Phase2["Phase 2: Retrieval & Generation (Runtime)"]
        direction TB
        user(["👤 User"]) --> query["❓ Question / Query"]
        query --> emb2["🧠 OpenAI Embedding Model"]
        emb2 --> search["🔍 Similarity Search (Cosine)"]
        vdb -.->|Stored Vectors| search
        search --> context["📑 Top-K Retrieved Passages"]
        
        query --> prompt["📝 Augmented Prompt (Context + Question)"]
        context --> prompt
        
        prompt --> llm["🤖 OpenAI LLM (gpt-4o / gpt-4o-mini)"]
        llm --> answer["💬 Grounded Response"]
        answer --> user
    end
